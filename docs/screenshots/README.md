## 怎么截

1. 浏览器打开 AstrBot 的 WebUI（默认 `http://<你的地址>:6185`），登录；
2. 进入 **插件管理 → QQ 群管理 → 面板**，切到对应页签；
3. 按 `F12` 打开开发者工具 → 点左上角手机/平板图标（设备工具栏）→ 分辨率设 **1440×900**（面板是宽屏布局，窄了会挤成一列）；
4. 按 `Ctrl+Shift+P`（Mac：`Cmd+Shift+P`）→ 输入 `Capture full size screenshot` → 回车，自动存整页 PNG；
   不想用命令面板就 `F11` 全屏 + 系统截图（Win：`Win+Shift+S`，Mac：`Cmd+Shift+4`）。
5. 存成上表里的文件名，放进本目录。

## 隐私

面板里会出现**真实群名、群号、成员昵称、openid**，这些不要出现在截图里：

- 优先用**测试群**截图；
- 或者先在「群规审核」页把群名手动备注成「示例群 A / B」；
- 截完检查一遍，必要时打码后再提交。

## 图片规格（够用即可）

- 宽度 1440–1920 px，PNG；
- 单张控制在 500 KB 内（必要时用 `pngquant` / Squoosh 压缩）；
- 不要带浏览器地址栏、书签栏和用户名。
